# Halo

Signed and notarized downloads of Halo, a native Mac app in the notch. The source is private.

## Install

```bash
brew install --cask josephgoksu/tap/halo
```

Or download `Halo.zip` from the [latest release](https://github.com/josephgoksu/halo-releases/releases/latest).

Halo needs a license key: https://halo.reaktif.io
